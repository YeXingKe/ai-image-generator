## 默认积分套餐（可被用户覆盖）

| 套餐 | 价格 | 积分 | 折合单价 |
|------|------|------|----------|
| 体验包 | 免费注册赠 | 10 | — |
| 基础包 | ¥9.9 | 50 | ¥0.198/次 |
| 标准包 | ¥29.9 | 200 | ¥0.149/次 |
| 专业包 | ¥99 | 800 | ¥0.124/次 |

## 默认积分消耗

| 操作 | 消耗 |
|------|------|
| 混元文生图 | 2 / 次 |
| GPT 文生图 | 3 / 次 |
| 图生图（任一模型） | 对应模型 +1 |

## 默认主流程（文字版）

```
注册/登录 → 获赠免费积分 → 选择模型 → 选择模式
→ 输入提示词（+参考图）→ 生成（预扣积分）→ 展示结果
→ 下载/重试 → 积分不足引导充值
```

## 默认生图状态机

```
idle → submitting → pending/processing → done
                                  ↘ failed（退积分）
```

## 默认成功指标

- 注册转化、首次出图率、付费转化率、次日留存、生成失败率、API 毛利率

## 默认 Phase 路线图

| 阶段 | 周期 | 内容 |
|------|------|------|
| Phase 1 | 1–2 周 | 登录 + 积分 + 混元文生图 |
| Phase 2 | 1 周 | GPT + 切换 + 图生图 |
| Phase 3 | 1 周 | 支付 + 历史优化 |
| Phase 4 | 持续 | UI、性能、风控、反馈迭代 |
